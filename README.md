# Przechowalnie

Prosta, responsywna strona z testem preferencji inspirowanym MBTI.

## Uruchomienie

Otwórz `index.html` w przeglądarce. Projekt nie wymaga instalacji zależności ani serwera.

## Struktura

- `index.html` - widok aplikacji i trzy stany: start, test, wynik
- `style.css` - responsywny interfejs
- `script.js` - pytania, naliczanie osi i opis wyniku
